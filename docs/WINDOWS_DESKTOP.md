# CBOS 2.0 Windows 离线版

Windows x64 安装包与 ZIP 包含 Electron、Python 后端、前端和帮助文档，无需服务器、Python 或 Node。计算、账号和数据库全部保存在本机，各部署互不共享。

## 安装与使用

从 v2.0.1 Release 下载 `CBOS-2.0.1-windows-x64-setup.exe` 或 `CBOS-2.0.1-windows-x64.zip`，按 SHA256SUMS.txt 核对。当前安装包未签名，发布者状态会如实显示在发行说明中。ZIP 完整解压后运行 CBOS.exe。

首次创建管理员，没有默认密码；以后每次启动登录。新安装的煤库为空，不附带或自动灌入原煤数据库。可在煤库页面下载六煤测试表，预览确认后导入练习，也可用空模板导入真实化验。已有用户记录保留，未知基准不会自动补齐。

数据默认位于当前用户 LOCALAPPDATA 下的 CBOS 目录，可用菜单“打开数据文件夹”定位。安装和数据目录分开；应用可安装在含空格、中文和百分号的路径。

## 备份与恢复

退出程序后复制整个用户数据目录（coal_system.db、.app-secret 等）。升级前迁移会生成 SQLite 一致性备份。卸载保留用户数据；如需删除数据，先备份后由用户自行处理。恢复时停止程序并用完整备份替换，禁止将不同部署的 SQLite 文件直接合并。

### 账号密码恢复

其他管理员可在“用户与权限”中重置密码。如果唯一管理员遗忘密码，先完全退出 CBOS，在 PowerShell 执行：

```powershell
& 'C:\实际安装目录\resources\backend\cbos-backend.exe' --reset-password admin --data-dir "$env:LOCALAPPDATA\CBOS"
```

替换实际程序路径、账号名和数据目录。ZIP 版使用解压目录下同一位置的程序，无需安装 Python。按提示隐藏输入两次至少 12 位的新密码，不接受密码命令参数。恢复仅修改现有账号并撤销全部会话；运行中的 CBOS 会锁住目录，需退出后重试。完成后重新启动并登录。此恢复操作依赖 Windows 用户对数据目录的访问权限，不要向无关人员开放该目录或备份。

更多内容见 [用户手册](USER_GUIDE.md) 和 [2.0 升级说明](UPGRADE_2.0.md)。

## 构建与验证

Windows x64 CI 安装依赖，构建前端、冻结后端，运行登录/混煤/置换比/导入导出/重启测试，生成 NSIS 和 ZIP。安装后的 Electron 在含中文和空格的目录启动，完成真实 UI 验证后卸载，确认用户数据保留。

版本从 app/__version__.py 同步至清单，构建步骤只检查、不修改版本。正式资产必须来自最终锁定的完整提交 SHA，不复用旧 PR 构建；构建清单和验证摘要一起发布。

## 通信与安全

渲染进程使用沙箱与 contextIsolation，无 Node 集成。主进程通过随机 loopback 端口通信，独立令牌每次启动轮换。登录 cookie 仅保存在主进程内存，退出清除；CSRF 仍由后端检查。日志不记录密码或会话令牌。
