## 1. 快速上手：界面总体

打开系统后，界面固定分为三部分：**左侧导航栏**、**顶栏**、**主内容区**。

### 1.1 左侧导航栏（六个入口）

导航栏是最左侧的竖排图标条，共六个入口。鼠标悬停在图标上会显示名称提示，当前所在页面的图标处于高亮状态。

| 图标 | 名称 | 用途 |
| --- | --- | --- |
| 房子 | **总览** | 控制台总览页，读数、最近活动与功能入口 |
| 数据库 | **煤种数据库** | 维护煤种指标，导入导出、批量管理 |
| 烧杯 | **智能混煤** | 选煤、定约束、NSGA-II 求解，得到推荐配比 |
| 天平 | **置换比计算** | 理论与实际置换比计算 |
| 历史 | **混煤历史** | 回看历次混煤优化结果 |
| 图表 | **置换比历史** | 回看历次置换比计算结果 |

导航栏顶部的炉膛图标为产品标识，悬停显示完整产品名。

### 1.2 顶栏（面包屑、服务状态、主题切换）

顶栏在主内容区上方，从左到右依次是：

- **面包屑**：左侧固定显示 `CBOS · 煤粉配煤控制台`，右侧显示当前页面标题（如「智能混煤优化」）。
- **演示数据标识**：当系统运行在演示模式时，会出现一枚橙色 **演示数据** 徽标（带闪电图标）。看到它说明当前使用的是内置合成数据、无需连接后端；详见[第 7 节](#7-主题演示模式与数据说明)。
- **服务状态徽标**：
  - 绿色「**服务在线 · <存储模式>**」——后端接口连通，`<存储模式>` 显示当前数据存储方式（如 `SQLite`）。
  - 红色「**服务离线**」——接口未连通。
  - 灰色「**检查中…**」——正在检测。系统每 60 秒自动复检一次。
- **主题切换按钮**：最右侧的太阳/月亮图标。点击可在暗色与亮色主题之间一键切换，选择会被本地记住，详见[第 7 节](#7-主题演示模式与数据说明)。

### 1.3 主内容区

主内容区展示当前页面。页面切换时会先显示占位骨架，加载完成后呈现真实内容。

## 2. 控制台总览页

点击导航栏「**总览**」进入。这是登录后的第一屏，用于快速了解系统状态并跳转到各功能。

### 2.1 顶部引导区

页面顶部是引导横幅，标题为「从一份煤种数据出发，配出最优喷吹煤」。下方有两个快捷按钮：

- **开始智能混煤**：直接进入[智能混煤](#4-智能混煤优化重点)页面。
- **管理煤种数据**：直接进入[煤种数据库](#3-煤种数据库)页面。

### 2.2 读数卡（四张统计卡）

引导区下方是四张读数卡，反映系统当前的整体数据：

| 读数卡 | 含义 |
| --- | --- |
| **煤种总数** | 数据库中已录入的煤种数量 |
| **混煤优化历史** | 已保存的混煤推荐方案条数 |
| **置换比历史** | 理论与实际置换比计算记录条数 |
| **平均求解耗时** | 最近若干次混煤求解的平均耗时（秒），无历史时显示 `—` |

### 2.3 功能入口卡（三张）

读数卡下方是三张功能入口卡，点击卡片即可进入对应功能：**煤种数据库**、**智能混煤优化**、**置换比计算**。每张卡上都有一句功能简介。

### 2.4 最近活动

页面左下方「**最近活动**」列表按时间倒序展示最近的混煤优化与置换比计算记录（最多 7 条）。

- 烧杯图标行代表一次**混煤优化**，显示参与的煤种名称与吨煤成本、综合热值。
- 天平图标行代表一次**置换比计算**，显示类型与置换比数值。
- 点击任意一行会跳转到对应的历史页面。右上角「**全部历史**」链接跳转到[混煤历史](#6-历史记录页)。
- 若没有任何记录，这里会提示「暂无历史活动」。

### 2.5 运行信息

页面右下方「**运行信息**」面板显示系统运行时状态：**应用**名称、**存储模式**、**煤种记录**数、**服务状态**。下方两个按钮可快捷跳转到「检查煤种数据」与「查看置换比历史」。

## 3. 煤种数据库

点击导航栏「**煤种数据库**」进入。此页维护煤种的工业分析与元素分析指标，是混煤优化的数据基础。

### 3.1 检索、类型筛选与分页

页面主体是一张煤种列表，表头工具栏提供三种过滤/翻页手段：

1. **搜索框**（放大镜图标）：输入关键字可按 `名称 / 类型 / 供应商` 检索，输入后自动过滤（有短暂延迟以减少抖动）。
2. **类型下拉框**：默认「所有类型」，可筛选特定煤种类型（如 `无烟煤`、`烟煤`、`贫煤`、`褐煤`、`其他`）。
3. **每页条数下拉框**：可选每页 `10 / 20 / 50` 条。

列表下方是**分页器**，显示「第 x–y 条 / 共 N 条」，并提供上一页、页码、下一页按钮。修改搜索或筛选条件时会自动回到第 1 页。

每一行显示：**煤种信息**（名称、类型标签、供应商与编号）、**价格**（元/吨）、**热值**（kcal/kg）、**灰分 %**、**挥发分 %**、**全硫 %**，以及行尾的操作按钮（详情、编辑、删除）。

### 3.2 添加 / 编辑煤种

- **添加**：点击页面右上角「**添加煤种**」按钮，右侧滑出录入抽屉。
- **编辑**：点击某行的**编辑**（铅笔）图标，抽屉会预填该煤种的现有数据。

录入抽屉将字段分成四组：

| 分组 | 字段（`必填` 标注为必填项） |
| --- | --- |
| **基础信息** | `煤种名称`（必填）、`煤种类型`（必填，下拉选择）、`供应商/产地`、`价格`（元/吨，必填） |
| **工业分析** | `热值`（kcal/kg，必填）、`灰分`（%，必填）、`挥发分`（%，必填）、`固定碳`（%，必填）、`全硫`（%，必填）、`全水分`（%）、`空干基水分`（%） |
| **元素分析** | `含碳量 C`（%）、`含氢量 H`（%）、`含氮量 N`（%） |
| **其他指标** | `可磨性 HGI`、`燃尽率`（%） |

**校验规则**：

- 所有标注为必填的字段不能为空；数值字段必须填写有效数字。
- **三组之和校验**：当同时填写了 `灰分`、`挥发分`、`固定碳` 时，三者之和须落在 **90–110** 之间，否则会在 `固定碳` 处提示「灰分+挥发分+固定碳应在 90–110 之间」。这是配煤领域的常识性一致性检查。

校验通过后，点击抽屉底部「**添加煤种**」/「**保存修改**」提交；提交成功会弹出提示并刷新列表。点击「**取消**」或抽屉外区域可关闭。

### 3.3 详情抽屉

点击某行的**详情**（眼睛）图标，右侧滑出只读详情抽屉，逐项列出该煤种的全部字段（含单位）。抽屉底部「**编辑此煤种**」按钮可直接切换到编辑模式。

### 3.4 批量选择、导出、模板与导入

**批量选择**：每行行首有复选框，表头复选框可一键全选/取消当前页；部分选中时表头显示半选状态。选中任意一项后，工具栏右侧出现「**已选 N 项**」以及两个批量操作按钮。

**导出**：

- **导出选中**（工具栏，选中后出现）：仅导出勾选的煤种。
- **导出全部**（页面右上角）：导出全部煤种。
- 连接真实后端时导出为 **Excel** 文件，文件名形如 `煤种数据导出_<时间戳>.xlsx`；演示模式下由内置引擎生成 `CSV`。前端会按返回的内容类型自动决定后缀。

**下载模板**：点击右上角「**导入模板**」按钮，下载导入模板（**Excel** 格式，后端下载名 `煤种数据导入模板.xlsx`）。批量导入时请务必按模板的列顺序填写。

**批量导入**：

1. 点击右上角「**批量导入**」按钮，弹出导入对话框（支持 `CSV`（演示模式）/ `Excel`（连接后端时））。
2. **点击虚线框选择文件**，或将文件**拖拽**到框内。列顺序需与导入模板一致。
3. 点击「**开始导入**」。完成后对话框内显示统计徽标：**新增 N**、**更新 N**、**跳过 N**；若有问题行，会在下方列出错误信息。

**删除**：

- 单条删除：点击某行的**删除**（垃圾桶）图标。
- 批量删除：选中若干条后，点击工具栏「**删除选中**」。
- 两者都会弹出确认对话框，提示「此操作不可撤销」，需点击「**确认删除**」才会执行。

## 4. 智能混煤优化（重点）

点击导航栏「**智能混煤**」进入。核心流程为：**选煤 → 定约束 → 配比边界 → NSGA-II 多目标求解 → 解读结果**。页面左侧是三步工作区，右侧是**求解面板**。您的选煤、约束与参数配置会自动保存在本地，下次进入自动恢复。

### 4.1 第 1 步：选择煤种（≥2 种）

在「**① 选择煤种**」面板中：

1. 使用**搜索框**与**类型下拉框**过滤候选煤种列表。
2. 点击某一行即可勾选/取消该煤种；每行显示价格、热值、灰分、硫分等关键指标以辅助判断。
3. 已选煤种会以标签（chip）形式列在面板下方，点击标签上的「×」可移除。
4. 面板右上角徽标实时显示「**已选 N 种**」。**至少选择 2 种煤**才能求解。

### 4.2 第 2 步：工艺约束窗口

在「**② 工艺约束窗口**」面板中锁定生产边界，求解器只会在此可行域内寻优。逐行设置：

| 约束项 | 单位 | 设置内容 |
| --- | --- | --- |
| **热值** | kcal/kg | `目标` 值，以及 `下限–上限` 范围 |
| **灰分** | % | `下限–上限` |
| **挥发分** | % | `下限–上限` |
| **固定碳** | % | `下限–上限` |
| **硫分** | % | `下限–上限` |
| **价格** | 元/吨 | `下限–上限` |

- 热值一行额外要求填写**目标值**，该目标须落在热值下限与上限之间。
- 每一项的**下限必须小于上限**。
- 点击面板底部「**恢复默认约束**」可一键重置为系统默认工艺窗口（保留已设置的配比边界）。

### 4.3 第 3 步：单煤配比边界

选煤后出现「**③ 单煤配比边界**」面板，用于限定每种煤在混合物中所占的百分比范围。

- **批量设置**：面板顶部输入统一的下限、上限（%），点击「**应用到全部**」，可一次性套用到所有已选煤种。
- **逐煤设置**：每种煤单独有一组 `下限–上限` 输入框（0–100）。
- **配比和校验**（面板底部两行）：
  - **配比下限之和** 必须 **≤ 100%**，否则标红提示 `> 100 ⚠`。
  - **配比上限之和** 必须 **≥ 100%**，否则标红提示 `< 100 ⚠`。
  - 这保证 100% 的总配比落在各煤上下限所围成的可行区间内。

### 4.4 求解档位与高级参数

右侧「**求解面板**」顶部显示已选煤种数与目标热值。下方「**求解档位**」提供三挡预设：

| 档位 | 特点 |
| --- | --- |
| **快速** | 小种群、少迭代，秒级出解，适合快速试算 |
| **标准** | 默认配置，兼顾精度与速度 |
| **精细** | 大种群、多迭代，追求最优 Pareto 前沿 |

如需微调算法内部参数，点击「**高级参数**」打开抽屉，可调整种群大小、最大迭代次数、变异率、交叉率、锦标赛大小、精英比例、早停耐心值、约束惩罚因子、并行线程、多样性因子等。修改高级参数后，档位会标注为「已自定义参数」。

### 4.5 预检查与开始求解

求解面板中部有一块**预检查横幅**：

- 全部条件满足时显示绿色「**预检查通过，可以开始求解**」，此时「**开始优化求解**」按钮可用。
- 存在问题时显示「**N 项需要调整**」，并列出前几条问题（如「至少选择 2 种煤」「配比下限之和超过 100%」「热值目标应在下限与上限之间」等）。逐条修正后按钮才会点亮。

点击「**开始优化求解**」后，按钮变为进度条并显示「NSGA-II 求解中 · 种群 xxx」。求解完成会弹出提示（生成的 Pareto 候选数量），并自动滚动到结果区。

### 4.6 结果解读

求解完成后，页面下方展示完整结果。

**结论横幅**（顶部）：

- 绿色「**已找到可行推荐方案**」——满足全部工艺硬约束。
- 红色「**当前约束下无可行方案**」——提示放宽最紧约束或增选煤种。
- 横幅右侧提供三个按钮：「**重新求解**」「**复制分享**」「**导出报告**」（见 [4.8](#48-导出报告与复制分享)）。

**可行方案下的内容**：

- **关键读数**（一排小卡）：`吨煤成本`、`综合热值`、`灰分`、`挥发分`、`硫分`、`质量风险`。
- **推荐配比**（环图）：以环形图 + 明细列表展示每种煤的推荐占比（%）。
- **约束余量雷达**：雷达图展示各指标相对约束区间的位置——越靠近中心越接近下限，越靠外越接近上限。
- **约束满足诊断**：逐项显示各指标当前值相对 `下限–上限` 的位置，落在区间内为绿色、越界为红色。
- **算法指标**（一排徽标）：贴边约束（哪些约束已顶到边界）、`迭代` 次数、`耗时`（秒）、`质量风险` 数值。

**无可行方案下的内容**：显示「**约束冲突诊断**」列表，逐条说明哪些约束发生冲突及具体原因，据此调整约束或煤种后重新求解。

### 4.7 Pareto 候选

在可行结果下方，「**Pareto 前沿 · N 个候选方案**」区域并排展示：

- 左侧**散点图**：每个点是一个候选方案，推荐方案会被特别标记。
- 右侧**方案表格**：列出每个方案的成本、热值、灰分、硫分、风险，标有「推荐」标签的即当前推荐解。

**点击散点或表格中的任意一行**，即可将上方的关键读数、推荐配比环图、约束诊断切换为该方案的数据，方便横向对比不同权衡下的方案（如更低成本 vs 更低风险）。

### 4.8 导出报告与复制分享

结论横幅右侧：

- **导出报告**：将当前结果导出为报告文件（`Excel` 或 `JSON`，视后端能力），文件名形如 `混煤优化报告_<时间戳>.xlsx`。仅在方案可行时可用。
- **复制分享**：把当前查看方案的配比、吨煤成本、综合热值、灰分/硫分、方案状态整理成一段文本复制到剪贴板，便于粘贴到聊天或工单。
- **重新求解**：用当前配置再跑一次（结果可能因随机性略有不同）。

### 4.9 典型操作提示与常见问题

- **推荐先用「快速」试算**，确认可行域合理、约束不冲突后，再切到「标准」或「精细」求正式方案。
- **无可行解怎么办？** 优先**放宽最紧的那条约束**（对照结论横幅下的「约束冲突诊断」找到冲突项），或**增加可选煤种**以扩大搜索空间。也可检查配比边界之和是否卡死了 100% 的落点。
- **配比和报红**：若下限之和 > 100% 或上限之和 < 100%，请回到第 3 步调整单煤边界（或用「批量设置」放宽）。
- **想比较多个方案**：在 Pareto 区域点选不同候选，观察成本与质量风险的取舍再做决定。

## 5. 置换比计算

点击导航栏「**置换比计算**」进入。此页计算高炉喷吹煤的置换比（单位统一为 **kg 焦 / kg 煤**），为煤比调整提供依据。页面右侧的「**计算结果**」面板始终显示当前置换比大数与操作按钮。

### 5.1 两种模式的切换

页面顶部有两张**模式卡**，点击切换（切换会重置输入与结果）：

- **理论置换比**：基于煤粉/焦炭成分与高炉工艺参数的碳氢热平衡模型，反映置换比的理论上限。
- **实际置换比**：基于焦比、煤比调整前后的生产数据反算，支持生产因素修正。

### 5.2 理论模式字段

理论模式下，左侧按三组填写参数（带 % 的字段界面按百分数录入）：

| 分组 | 字段（单位） |
| --- | --- |
| **煤粉参数** | `含碳量`（%）、`含氢量`（%）、`灰分`（%）、`灰中 SiO₂`（%）、`分解热`（kcal/kg）、`物理热`（kcal/kg） |
| **焦炭参数** | `含碳量`（%）、`灰分`（%）、`灰中 SiO₂`（%） |
| **高炉工艺参数** | `煤气利用率 ηCO`、`炉渣碱度`、`炉渣热焓`（kJ/kg）、`风温`（°C）、`鼓风热焓`（kJ/m³） |

### 5.3 实际模式字段

实际模式下，左侧先填写一组基础数据：

| 分组 | 字段（单位） |
| --- | --- |
| **基础生产数据** | `调整前焦比`（kg/t）、`调整后焦比`（kg/t）、`调整前煤比`（kg/t）、`调整后煤比`（kg/t）、`修正系数`（kg/t） |

下方是「**生产因素修正**」面板，带一个开关：

- 关闭时（默认），三项修正字段变灰不可编辑，按 0 处理，仅计算基础置换比。
- 打开「**启用修正**」后，可填写 `铁水产量变化`（t/d）、`渣比变化`（kg/t）、`碳利用效率变化`（%），将产量、渣比与碳效率的影响纳入计算。

### 5.4 载入示例 / 重置 / 开始计算

右侧「**计算结果**」面板的操作区：

- **载入示例**：一键填入一组示例参数，便于快速试算或熟悉字段。
- **重置**：恢复当前模式的默认值并清空结果。
- **开始计算**：提交计算。完成后大数区显示置换比（保留 4 位小数），并弹出提示。面板右上角徽标标明本次为「理论」「实际·基础」还是「实际·修正」。

### 5.5 结果与明细

- **计算结果大数**：右侧面板中央显示本次置换比，下方标注单位 `kg 焦 / kg 煤`。
- **计算明细**：计算成功后，左侧出现「**计算明细**」面板，逐项列出中间量数值；右侧的「**构成占比**」环图展示各组成项对结果的贡献占比（如煤粉含碳量、氢还原节约碳、灰分造渣耗碳、分解/物理热耗碳等）。

## 6. 历史记录页

系统把每一次混煤优化与置换比计算都持久化保存，可随时回看。

### 6.1 混煤优化历史

点击导航栏「**混煤历史**」进入。

- **顶部读数卡**：`历史记录` 总数、`可行方案` 数、`平均吨煤成本`、`最近运行` 时间。
- **筛选**：搜索框可按**煤种名称**过滤；分段控件可切换「全部 / 可行 / 不可行」。
- **列表**：每行显示时间、煤种与配比（标签形式，最多展示 3 种，多余以 `+N` 折叠）、吨煤成本、热值、硫分、可行性徽标。
- **分页**：每页 8 条，底部提供上一页/下一页与页码。
- **详情抽屉**：点击某行「**详情**」，右侧滑出抽屉，展示可行性结论、推荐配比环图与明细、关键指标（吨煤成本、综合热值、灰分、挥发分、固定碳、硫分、迭代次数、计算耗时、质量风险）。
- **查看原始数据**：抽屉底部「**查看原始请求/结果**」可展开，查看该次运行的请求快照与结果快照（JSON）。

### 6.2 置换比计算历史

点击导航栏「**置换比历史**」进入。

- **顶部读数卡**：`历史记录` 总数、`理论置换比` 条数、`实际置换比` 条数、`最近结果` 数值。
- **筛选**：搜索框可按**参数摘要**过滤；分段控件可切换「全部 / 理论 / 基础 / 修正」。
- **列表**：每行显示时间、类型（理论/实际）、模式（理论模型/基础/生产修正）、置换比数值、参数摘要。
- **分页**：每页 10 条。
- **详情抽屉**：点击某行「**详情**」，右侧滑出抽屉，展示置换比大数、类型与模式徽标、参数摘要、计算明细，以及可展开的「**查看原始请求/结果**」（JSON 快照）。

## 7. 主题、演示模式与数据说明

### 7.1 双主题与切换

系统提供两套主题，通过顶栏最右侧的**太阳/月亮图标**按钮一键切换：

- **暗色主题（Furnace Console）**：默认，低亮度炉膛风格，适合控制室环境。
- **亮色主题（Foundry Daylight）**：高亮度，适合明亮办公场景。

主题选择会被浏览器本地记住，下次打开自动沿用，无需重新设置。

### 7.2 演示模式

系统支持**演示模式**：开启时使用内置的合成数据与算法引擎（合成 NSGA-II 与置换比引擎），无需连接后端即可完整体验选煤、求解、置换比计算与历史功能。

- **如何识别**：顶栏出现橙色「**演示数据**」徽标即为演示模式。
- **用途**：培训、演示、离线试用。演示模式下的数据为示例数据，不代表真实生产库。
- 生产部署默认关闭演示模式，直连真实后端与数据库。

### 7.3 数据同源与持久化

- **单一数据源**：总览读数、煤种列表、混煤与置换比历史均来自同一后端数据源（生产环境默认 `SQLite` 数据库，也可切换为其他数据库）。因此在煤种数据库中新增/修改煤种后，总览读数与混煤选煤列表会同步更新。
- **服务器端持久化**：每次混煤优化与置换比计算的结果都会保存到后端，可在对应的历史页长期回看，并可查看当次的原始请求/结果快照。
- **本地记忆**：主题选择、以及智能混煤页的选煤、约束与算法参数配置会保存在浏览器本地，方便下次继续，不影响服务器数据。
