# 2.0.1 界面与使用说明

本版针对 Windows 和 Web 共用界面调整，保留深色橙色主题，同时支持亮色主题。

## 开始使用

新安装不包含原有煤种资料。登录后，在“煤质数据库”录入自己的报告；也可以展开“需要练习数据？下载六煤测试表”下载 XLSX 或 CSV 测试表，通过“导入 / 粘贴”的预览步骤确认导入。

测试表包含 3 种无烟煤和 3 种烟煤，统一标注为合成教学数据。它保留各指标原始基准、热值定义、报价和辅助化验字段，用于练习导入、统一基准计算和结果核对。下载或预览本身不会建立煤种；重复导入遵循普通修订规则。

已有账号、煤质和历史记录继续保留。日常操作不需要选择数据迁移方式。

## 页面变化

| 页面 | 调整 |
| --- | --- |
| 侧边菜单 | 默认显示图标和文字，按日常工作、计算记录、系统管理、帮助与账号排列；支持折叠并按账号记忆 |
| 工作台 | 显示真实批次可用性、常用功能、最近计算和当前计算口径；空库提供明确的录入起点 |
| 置换比 | 内容居中，表单与结果分栏；窄窗口自动排列为单列 |
| 使用帮助 | 日常操作目录、清晰标题、真实表格和列表，技术资料收纳在高级参考 |
| 关于 | 版本、构建、运行方式和功能说明；更新记录保留在 CHANGELOG 和 Release 中 |
| 设置与账号 | 统一表单间距、成对的上下限输入与卡片宽度 |

Windows 文档换行符已被统一处理，帮助内容在网页及离线程序中保持相同结构。窄窗口通过顶部按钮展开菜单，点击页面或按 Esc 关闭。

## 安装与核对

从对应的 [GitHub Release](https://github.com/kevinalliswell/coal-database-blending-system-web/releases/tag/v2.0.1) 获取 Windows 安装包 / ZIP 或 Docker 离线镜像。Windows 资产未签名。安装前核对 `SHA256SUMS.txt`；安装后在“关于”中核对版本和构建标识。

运行和备份说明见 [Windows 指南](WINDOWS_DESKTOP.md) 和 [Web 部署](DEPLOYMENT.md)，日常操作见 [用户手册](USER_GUIDE.md)。本次不改变煤质换算公式、LP 预检或 NSGA-II 优化目标。
