# 置换比热量字段修复

`hot_blast_enthalpy` 原先被忽略，现在显式输入以 **kJ/m³** 参与计算：

`Q_C = 1.2 × H_blast + 9794 − 2758`（kJ/kg C）。

省略或传 `null` 时，保留旧的 `H_blast ≈ 1.3 × wind_temperature` 工程估算；提供数值时覆盖该估算。响应及历史记录给出实际采用的焓值和来源。模型风量和焓值必须采用相同体积口径。前端默认使用风温估算，实测输入需显式启用。

旧前端的 `1.5 kJ/m³` 默认值被删除。不会猜测用户是否想输入 MJ/m³，也不会自动乘 1000；旧客户端若一直传入 1.5，现在该值会实际参与计算，应改为 null 或经确认的 kJ/m³ 化验/工艺值。此行为修正可能改变旧客户端结果。

`decomposition_heat_consumption` 现在只返回分解热；`physical_heat_consumption` 返回物理热；新增 `total_heat_consumption` 为二者之和，单位均为 kcal/kg。内部等效耗碳仍仅扣减一次 `(H_decomp+H_physical)×4.184/Q_C`。

所有理论计算输入先验证对象形状、有限值和单位范围，非正焦炭有效碳量返回 400。演示模型同步采用同一热平衡公式。修改参数、载入示例或切换修正模式后清除旧结果，求解期间禁用输入。

验证：15 项新增回归先复现再修复，覆盖实测优先、缺省估算、风温响应、能量平衡、独立热量字段、非有限输入和负分母。完整 API 示例由实际计算生成。此修复没有完成经验系数与现场工况的标定，模型应作为简化估算使用。
